✦ ABOUT THE ARCHIVE

关于本项目

Open Character Cards 是一个基于 GitHub 的开源角色卡分享平台。 每张角色卡就是一张 SillyTavern 格式的 PNG —— 人设、开场白、对话示例全部内嵌在图片里， 下载、导入酒馆，就能开始一段新的故事。

国内能好好放角色卡的地方太少，于是我们把它做成一个仓库：投稿只需要传一张图， 自动校验、自动上线、永久留存。不懂代码的人开 Issue，懂代码的人发 PR，两条路都通。

8已收录角色卡
MIT源代码授权协议
100%静态站点 · 无后端
01

开源免费

代码 MIT 授权，角色卡按各自协议共享。没有会员、没有付费墙，所有资源永久可下载。

02

GitHub 托管

图片即数据，仓库即数据库。每一版角色卡都留在提交历史里，不依赖任何一家的服务器。

03

社区共建

投稿、纠错、补充标签都欢迎。机器人负责校验与分流，维护者只处理边界情况。

想放一张自己的角色卡进来？

开一个 Issue，把 PNG 拖进去 —— 其余交给流水线。

✦ HOW TO TAKE A CHARACTER HOME

使用指南

三步，把喜欢的角色带进你的故事。

01

挑选角色

按名称、标签或分类找到喜欢的角色，先看看 TA 的故事再决定。

02

带走 PNG

在详情里下载原始 PNG，角色设定完整保留在文件中，不丢一个字段。

03

在酒馆开聊

导入 SillyTavern 或其他兼容前端，就可以开始新的故事了。
