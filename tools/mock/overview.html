六个页面

同一套 token 贯穿。每张图的标注说明的是「这一屏在解决什么」。

01 · 首页 Home

左文右图，右侧人物半身溢出底边、身后压一轮月晕 —— 让 hero 有纵深，而不是把插画平铺当背景。

  • 标题 56px 衬线，一句主标题 + 金色副标题 + 两行说明，四层信息一次读到底
  • 精选卡悬停态在第一张常显（金色描边 + 底部「查看角色卡」按钮），方便验收交互
  • 卡片图放大到 150% 顶部对齐，人物是半身特写而不是全身缩略
02 · 角色卡画廊 Gallery

左栏 302px 固定筛选，右侧 4×2 网格，一屏看完 8 张。

  • 分类改为「选中即高亮」的整行状态，带数量角标
  • 标签做成圆角胶囊，多选态用金色描边
  • 补排序下拉（现有代码里缺这一项）
03 · 卡片详情 Detail

960×600 浮层，左 440 立绘 / 右信息，背景压暗并虚化。

  • facts 改双列（世界观·创作者 / 数据·收录），比原来单列 3 行更紧凑
  • 加一条分隔线把「描述」和「元信息」切开
  • 下载 / 收藏贴底，授权说明靠右，动作区与阅读区分离
04 · 关于页 About

两栏：左边讲项目缘起，右边一组数字（8 张卡 / MIT / 无后端）。三段内容纵向均分，不留大片空洞。

  • 标题改用无衬线 44px，与全站标题统一（衬线只留给英文主标题和角色名）
  • 三张能力卡 min-height 190，图文对齐；底部 CTA 条压一层金色微光
05 · 首页下半屏 Guide + Tool

三步指南 + 工具箱，内容垂直居中，滚动时 sticky 顶栏仍在。

  • 步骤卡带 01/02/03 编号与底部金色短线
  • 工具箱：左侧拖拽区 + 右侧解析结果，改成卡片行而不是表格
06 · 移动端 Mobile

390×844。竖版 hero + 2 列网格，一屏装下首屏全部关键动作。

  • hero 366px，人物压在圆形月光盘上，底部渐隐接入正文
  • 正文上移 80px 与 hero 衔接，标题 21px 不顶边
  • 两列卡片保留名字 + 标签，不做纯图墙
