# Open Character Cards — 页面设计稿

> 交付日期：2026-10-20 · 设计依据：用户提供的参考图 + 项目现有 `_variables.scss` 与 6 个 Vue 组件
> 出图源文件：`tools/mock/design.html` · 截图脚本：`tools/mock/shots.mjs` · 成品图：`tools/mock/out/*.png`

## 结论先行

1. **没有换品牌色，只重做版式。** 深空底 `#050a14`、暖金 `#ffdb6b`、月光蓝 `#a8c6ff` 全部沿用现有 token，改的是信息层级、间距节奏和卡片构图。
2. **六个页面按真实视口出图**（桌面 1440×900 / 移动 390×844），不是缩略拼贴，可以直接和真机对照。
3. **改动以 CSS 为主**：卡片构图、hero 层次、facts 双列、动作区贴底都不需要动数据结构；只有画廊分类侧栏（整行高亮 + 数量角标）和关于页数据块要动模板。排序下拉 `CardsPage` 原本就有，只是换了位置与样式。
4. **人物素材是示意图，不能直接上线。** 7 张 AI 生成立绘用于凑满画廊展示，真实投稿后需替换。

## 一、风格锚点（逐字复用，不得逐批改写）

> 星夜档案馆 / Moonlit Archive：深夜蓝底（#050a14 → #0b1a33）承托单一暖金光源；英文主标题用 Georgia 衬线、其余全无衬线；卡片为 3:4 竖幅、12–14px 圆角、1px 低对比描边；人物半身特写压在深色径向渐变上，底部渐隐融入底色；所有装饰线为 1px 金色半透明，禁止大面积高饱和色块与硬阴影。

**参考坐标**：项目现有首页 hero + `CardTile` 的圆角语言；色调参考用户提供的第一版展示板。

**禁忌清单**

- 不用纯白 / 浅灰做大面积底色（当前为全暗色主题，出现亮底会把视觉重心撕开）
- 不给卡片加硬投影（用 0 0 0 1px 内描边 + 低透明度外发光替代）
- 不混用第三种强调色（除暖金、月光蓝外，只用功能色 `#8fd8b0`）
- 中文标题不用衬线（衬线只保留给英文主标题与角色名）

## 二、色彩与明度

| 角色 | 色号 | 用途 | 对比度（对 #050a14） |
|---|---|---|---|
| 深空底 | `#050a14` | 页面底 | — |
| 区块底 | `#081426` | 精选区 / 关于区块 | — |
| 面板 | `#0b1a33` | 卡片、工具箱 | — |
| 描边 | `#1a2a4a` | 卡片边、分隔线 | — |
| 正文 | `#e6eaf3` | 主文字 | 16.4:1 |
| 次要 | `#b7c5dc` | 描述、说明 | 11.4:1 |
| 辅助 | `#8496b4` | 标签、计数、kicker | 6.6:1 |
| 暖金 | `#ffdb6b` | CTA、选中态、强调数字 | 14.7:1 |
| 月光蓝 | `#a8c6ff` | 光晕、次要强调 | 11.5:1 |

实测对比度取自截图脚本的 `[probe]` 输出，三级文字全部高于 WCAG AA 的 4.5:1。

**明度分层规则**：主体（人物 / 图片）> 标题 > 正文 > 辅助，卡片内必须靠底部渐变把图片压到与面板同明度区间，否则图会「浮」在卡片外。

**卡片构图规格（最关键的改动）**

- 容器：`aspect-ratio: 3/4`，圆角 12（精选）/ 14（画廊），`overflow: hidden`
- 图片：`position:absolute; top:-1%; left:50%; translateX(-50%); height:150%; width:auto`
- 底部遮罩：`linear-gradient(0deg, rgba(6,16,33,.82), transparent)`，高度 40%
- 悬停态：描边转 `rgba(255,219,107,.5)`，遮罩加深到 64%，底部浮出「查看角色卡」按钮（32px 高，金色实心）

## 六、复现方式

```bash
# 1. 改完 design.html 后重新出图
node tools/mock/shots.mjs

# 2. 单独重出一张
node tools/mock/shots.mjs --only=02

# 3. 重新抠图（新增立绘时）
python tools/mock/keyout.py tools/mock/assets tools/mock/assets/cut

# 4. 抹掉生图水印（新素材入库前跑一次）
python tools/mock/dewater.py bailing xiachuan

# 5. 重新生成角色卡 + 清单
node tools/make-cards.mjs && node tools/build-manifest.mjs
```

截图脚本会在出图前打印两行自检：`[probe]` 是三级文字对比度，`[shot]` 是每个框架的裁切检查（会指出哪个元素被最近的 `overflow:hidden` 祖先切掉多少 px）。
